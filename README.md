# ComfyUI-AIMoJingTools

> **秒哒 图像加载与遮罩输出** —— 专为 ComfyUI 设计的四合一高集成度图像算子节点。

集成「本地图像加载」、「上游图像接入与本地自动屏蔽」、「有效图像输出保障」、「遮罩按需条件输出」四项核心能力。

---

## ✨ 核心特性

- **四合一算子集成**：一个节点搞定图像读取、上游透传与遮罩提取。
- **输入接入自动屏蔽本地图像 + 来源切换开关**：
  - 增加 `source_mode` 切换开关（默认 `auto`）。
  - 当 `image_in` 接口连接时，自动切断并屏蔽本地选择的图像文件，优先透传上游图像；也可通过开关强制上游或强制本地。
- **图像与遮罩输出解耦，保障图像输出**：
  - 确保主图像端口（`image`）始终输出标准的有效 RGB 张量，彻底解决只输出遮罩层的问题。
- **未编辑遮罩时不输出遮罩图层**：
  - 未使用遮罩编辑器（Mask Editor）编辑时，不输出遮罩图层（全 0 空遮罩），彻底避免无遮罩时误覆盖图像画面。
- **无感 EXIF 旋转修正**：内置 `exif_transpose` 纠正拍摄方向，手机实拍图像绝不倒置。
- **零额外依赖**：仅依赖 ComfyUI 自带的标准 Python 环境。

## 📦 安装方法

### 直接放入 custom_nodes 目录

1. 将本目录 `ComfyUI-AIMoJingTools` 拷贝至 ComfyUI 的 `custom_nodes/` 目录下：
   ```bash
   cd ComfyUI/custom_nodes/
   git clone <本仓库地址> ComfyUI-AIMoJingTools
   ```
2. 重启 ComfyUI。
3. 在节点检索栏中搜索 `秒哒 图像加载与遮罩输出` 或 `MiaodaImageLoadWithMask`（分类：`image/loaders`）即可添加使用。

## 🔌 接口契约说明

### 输入项

| 参数名 | 类型 | 必选/可选 | 说明 |
| :--- | :--- | :--- | :--- |
| **`image`** | COMBO (`image_upload: True`) | **必选** | 支持在 Web UI 上传新图或选择已有图片 |
| **`source_mode`** | COMBO | 必选 | 来源切换开关：`auto (上游优先并屏蔽本地)` / `image_in (强制上游)` / `local_file (强制本地)` |
| **`mask_behavior`** | COMBO | 必选 | 遮罩行为：`auto (仅编辑时输出遮罩)` / `always_output` / `disabled` |
| **`image_in`** | `IMAGE` | *可选* | 接收上游节点的图像输入。连接时默认自动屏蔽本地文件 |

### 输出项

| 端口名 | 类型 | 张量格式 | 说明 |
| :--- | :--- | :--- | :--- |
| **`image`** | `IMAGE` | `(B, H, W, 3)`, float32, 0~1 | 规范化有效 RGB 图像张量，直连下游 |
| **`mask`** | `MASK` | `(B, H, W)`, float32, 0~1 | 遮罩张量。未编辑时输出全 0 空遮罩，不遮盖原图 |
